# uwuify
A C version of [owoify](https://pypi.org/project/owoify-py/). Currently quite limited.

## Building
You can use either `make` or, you can compile `target.c` on its own. `make` may not work on Windows.

Note that the output of `make` has debug symbols, run `make strip` to remove them.
